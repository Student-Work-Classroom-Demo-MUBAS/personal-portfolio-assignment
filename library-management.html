Library Management System

Organising library records and common library operations.

Case study in progress

This overview draws on the existing project summary. My individual contribution, exact implementation details, test evidence and personal lessons still need to be added.

The problem Project approach Tools and components Current evidence and results Possible next steps

The problem

Library records need to be organised so that users can find information and routine operations can be handled consistently. This project explores a software-based approach to managing those records.

Project approach

The project covers library-record management and common library operations. The available sequence diagram describes login and book search interactions. It provides a starting point for explaining how a user request moves through the system.

Tools and components

Software design, data management and sequence modelling. The implementation language, database, application framework and diagramming tool still need to be confirmed.

Current evidence and results

A sequence diagram is available for login and book search. Screenshots of a running application, database constraints and functional test results have not yet been documented here.

Possible next steps

Suggested next evaluation: record the implemented workflows and test successful and unsuccessful searches, invalid login input and the handling of duplicate or missing records.
