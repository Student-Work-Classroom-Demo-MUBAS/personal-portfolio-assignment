Smart Irrigation

Sensor-based watering with a web monitoring dashboard.

Case study in progress

This overview draws on the existing project summary. My individual contribution, exact implementation details, test evidence and personal lessons still need to be added.

The problem Project approach Tools and components Current evidence and results Possible next steps

The problem

Watering decisions need to reflect conditions around the plants. This project explores using environmental measurements to support automated irrigation instead of relying only on a fixed watering routine.

Project approach

The project combines environmental sensing, watering control and web-based monitoring. The prototype image shows a soil-moisture reading. The monitoring interface is intended to make the system state easier to inspect alongside the measurements used for watering decisions.

Tools and components

Environmental sensors, embedded control hardware and a web monitoring dashboard. The exact sensor models, controller, watering hardware and software stack still need to be recorded.

Current evidence and results

A prototype image is available. Sensor calibration, watering thresholds, operating trials and any measured water savings have not yet been documented here.

Possible next steps

Suggested next evaluation: calibrate readings for the soil used, compare dry and wet conditions, and check the response to a disconnected sensor before testing unattended watering.
