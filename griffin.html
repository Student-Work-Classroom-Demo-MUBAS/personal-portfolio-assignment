GRIFFIN

Remote fuel monitoring for telecom tower generator sites.

Case study in progress

This overview draws on the existing project summary. My individual contribution, exact implementation details, test evidence and personal lessons still need to be added.

The problem Project approach Tools and components Current evidence and results Possible next steps

The problem

Generator sites need a way to monitor fuel without relying entirely on visits to each location. GRIFFIN brings embedded measurements and a remote dashboard into one monitoring system.

Project approach

The project connects embedded sensing, data communication, backend services and a web dashboard. The prototype pictured here includes a microcontroller, a flow sensor, a pump and tubing. The intended information path runs from a physical measurement to a reading that can be reviewed remotely.

Tools and components

Microcontroller, flow sensor, pump, tubing, backend services and a web dashboard. Exact board models, programming languages and communication protocols still need to be documented.

Current evidence and results

The portfolio includes a photograph of the prototype. Measurement accuracy, communication reliability and field-test results have not yet been documented here.

Possible next steps

Suggested next evaluation: compare readings against a known reference, record measurement error and test what the dashboard shows when communication stops.
