Featured Project

GRIFFIN Fuel Monitoring System

A remote fuel monitoring system for telecommunications tower generator sites, combining embedded sensing, data communication, backend services and a web dashboard.

Embedded IoT Web

01 / Problem

The engineering problem

Telecommunication sites often depend on backup generators where grid power is unreliable. Monitoring fuel manually can make it difficult to detect unusual fuel loss, leakage or abnormal consumption quickly.

GRIFFIN addresses this by collecting fuel-related measurements electronically and sending them to a central system for remote monitoring and analysis.

02 / Contribution

What I worked on

My work has focused on both the embedded system and the software platform. I worked with an ESP32 microcontroller and sensors used to measure fuel level, fuel flow and electrical load. This involved sensor interfacing, calibration, signal conditioning and firmware development.

The ESP32 collects sensor readings and prepares them for transmission to the backend. The backend stores the measurements in a database, while a web dashboard presents information such as fuel level, flow rate, load and system status.

I have also worked on the system architecture and on how the collected data can be used to identify conditions such as normal consumption, heavy consumption, leakage, fuel delivery and possible fuel theft.

04 / Reflection

What I learned

GRIFFIN has taught me that embedded development involves much more than connecting sensors and writing code. Calibration, grounding, voltage levels, noisy measurements and hardware limitations can directly affect the reliability of the complete system.

If I restarted the project, I would establish a more structured sensor calibration and data-collection process earlier. This would provide more reliable measurements before implementing higher-level features such as classification and predictive analysis.
