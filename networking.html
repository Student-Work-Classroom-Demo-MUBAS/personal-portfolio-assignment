The problem

Devices on a home network need an addressing plan and correctly configured connections to communicate. This project focuses on designing and configuring two small networks.

Project approach

The work described in the portfolio covers network design, IP addressing, device connectivity and communication testing between hosts. A useful final report will connect the network diagram to the address assigned to each device and the tests performed.

Tools and components

IP addressing, network-device configuration and host connectivity tests. The devices, simulator or physical lab environment and diagnostic commands still need to be named.

Current evidence and results

Communication testing between hosts is recorded in the existing project summary. The actual outputs, topology diagrams and pass/fail observations are not yet included. The image on this page is an illustration, not test evidence.

Possible next steps

Suggested next evaluation: add an addressing table, capture connectivity-test outputs and compare the observed behaviour with the expected communication paths.
